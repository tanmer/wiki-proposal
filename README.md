# [Baklib Wiki 模板]

通过Proposal 方案书模板，你可以在线制作B2B 商业方案书，客户方案，项目策划方案，营销活动方案，以及电子书等等。

参考教程： https://help.baklib.cn/themes/proposal

## 目录结果

```
  ├── assets
  ├── config
  ├── layout
  │   └── theme.liquid
  ├── snippets
  │   ├── _feedback_form.liquid
  │   ├── _footer.liquid
  │   ├── _header.liquid
  │   ├── _page.liquid
  │   ├── _paginate.liquid
  ├── statics
  │   ├── ebook.liquid
  ├── templates
  │   ├── page.channel.liquid
  │   ├── page.liquid
  │   ├── page.ppt.liquid
```
